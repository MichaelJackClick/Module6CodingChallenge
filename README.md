# Module 6 Coding Challenge: Teen Hangout

This continues the [Module 6 Lab](https://github.com/MichaelJackClick/Module6Lab2505) with two more members and two more posts. The C# Razor Page uses arrays, foreach loops, and if statements to display:

- All five members.
- All five posts.
- Popular posts with 20 or more likes.
- Members age 16 or older.
- Posts with fewer than 20 likes.

## Run in GitHub Codespaces

1. Click **Code**, then **Codespaces**. Open a codespace or create one on **main**.
2. In the terminal, run:

   ```sh
   cd TeenHangout
   dotnet run
   ```

3. Open the forwarded port **5088** in the browser.
4. Press **Ctrl+C** in the terminal when finished.

The codespace configuration includes .NET 8 and the C# Dev Kit. To run locally, install the .NET 8 SDK and use the same commands.
